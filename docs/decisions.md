# Decisions

## Made

| # | Decision | Why | Date |
|---|---|---|---|
| 1 | The judge app is phone-first (390px); the admin console is desktop-first but must work on phones | Judges walk table to table; 2026 judges got lost and some teams were never judged | 2026-10-11 |
| 2 | UI follows the HackIllinois 2027 Figma brand: Ultra / Oswald / Manrope, purple ground, white chamfered cards with a hard ledge, gold primary | One brand across registration, website and judging | 2026-10-11 |
| 3 | Auth: judges use a magic link or QR from the check-in desk (no account); staff and admins use the Google OAuth adonix already has (`Provider.GOOGLE`, `@hackillinois.org`), with roles in adonix (`Role.STAFF`/`ADMIN`). Judges need a new `Role.JUDGE` plus a magic-link endpoint that issues the same adonix JWT | Judges must be in within seconds; staff identity and roles already live in adonix | 2026-10-11 |
| 4 | Round 1 is pairwise: from the second project on, the judge compares their last two. No ties. 8-second undo before a vote commits | Pairwise is the least biased; undo covers mis-taps while walking | 2026-10-11 |
| 5 | Skipping a project needs a reason: absent → re-queue, can't find → ping staff, conflict → never shown to that judge again | Fixes "some teams never got judged" | 2026-10-11 |
| 6 | Offline-tolerant judging: evaluations and votes queue on the phone and send on reconnect | Venue Wi-Fi | 2026-10-11 |
| 7 | Anti-cheat flags (late commits, unregistered member, path mismatch, team size, prior project) hold a project out of the queue until an admin clears it | Matches the Notion spec; evidence-first copy | 2026-10-11 |
| 8 | Staff/admin permissions follow one matrix (design-system README → Admin rules) | The spec's staff rules for Admissions were ambiguous; this is the reading we chose | 2026-10-11 |
| 9 | Stack follows the HackIllinois org (github.com/HackIllinois): the app is **Next.js 15 + React 19 on Cloudflare via OpenNext** (like `site` and `admin-site`) in the empty `HackIllinois/GavIL` repo; data and auth live in **adonix** (Express 5 + MongoDB/Typegoose + zod-to-openapi), extending its existing `judge` service; the client is generated from adonix's OpenAPI with `@hey-api/openapi-ts`, as `admin-site` does | One backend, one auth, one deploy target the team already runs. Replaces the earlier Next.js + Postgres option | 2026-10-11 |
| 10 | Admin tabs designed: Judges (check-in, sign-in links), Assignments (judge → room), Prizes & paths, Reimbursements (approve/deny), Settings (add/remove `@hackillinois.org` staff, change role) | They were placeholders; every tab in the console now works | 2026-10-11 |
| 11 | Visual direction is **bold rodeo / old west** on the 2027 brand: poster-paper cards, saloon-wood chrome, signpost wayfinding, rubber-stamp statuses, sheriff star, rosettes (2027 Theme Moodboard + Website signpost nav). Room and table numbers stay in Oswald for legibility; Rye only for short sign lettering | Aritro asked for rodeo; reviewers (Codex, Cursor) flagged Rye on wayfinding | 2026-10-11 |
| 12 | Comparison is always **this project vs the judge's previous one** (original Gavel); the next project is coverage-first, then max information gain vs the previous project. μ is only compared within a room; Pro/General overall winners come from a Round 2 final of each room's top 3 | Judges can't recall projects from an hour ago; rooms form disconnected comparison graphs | 2026-10-11 |
| 13 | Judge auth hardening: email code/link with 5 tries, two-step POST redemption, staff-issued single-use QR bound to the judge, event-scoped JWT with instant revocation, per-email (not per-IP) limits | External review: the desk QR was an unbound bearer login | 2026-10-11 |
| 14 | **Table talk** is a recording of the table conversation, taken only after the team agrees out loud and the judge taps: no audio is stored, no speaker is identified, no diarization, and the feature is **off by default per event** until counsel signs off. If the team declines, the judge dictates a private memo of their own voice **after leaving the table**. Highlights only describe; a prize suggestion needs a verbatim quote and the judge's own tap, and **Most Popular is never suggested** | Illinois is where we judge. The Eavesdropping Act (720 ILCS 5/14-2) makes it an offense to surreptitiously record a private conversation without the consent of all parties, and BIPA (740 ILCS 14/10) lists a voiceprint as biometric data; the suits against AI notetakers (Fireflies, Otter) turn on diarization, so we do none of it. A judge's memo of their own voice is a different thing from a recording of the team | 2026-10-13 |
| 15 | Table talk is **signed and metered**: every transcript comes back as a receipt (judge, project, visit, mode, consent time, the segments' hash, the duration; 30 min) and every vendor call is spent through a **server-signed, single-use, 60-second proof** only the Gav-IL server holds. A consent time only counts inside the visit's window (from 60 s before the judge reached the table to 2 min ahead of the server's clock). Quotas are 2 transcriptions and 3 Claude calls per judge per project, with event budgets of 1500 and 400. Claude highlights cannot be switched on until an admin records a **vendor-retention acknowledgement** (who and when, audited) | A judge must not be able to present "the team said X" for a transcript the server never produced, or spend the event's money. The acknowledgement records that zero data retention was requested from Anthropic and that only non-Covered models are used | 2026-10-13 |
| 16 | A **memo is a memo**: it may only be dictated after the judge has left the table (15-minute window), and never while they are sitting at any table | The same consent rule has to hold for the judge's own voice: the mic would otherwise pick up a team that never said yes, or one that opted out | 2026-10-13 |
| 17 | Every table gets a **printed placard** with a room-qualified code (the room letter + the 2-digit table number, e.g. `A12` = Room 4217, table 12), a **2-character check printed only on the placard** (`A12 · K7`) and a QR that encodes the **table, not the project**. The judge scans it, or types the code and the check, before notes, nominations and Submit open. A **name check-in is an attestation, not proof**: it opens the notes but **holds that evaluation's nominations** until a placard proof lands at the same visit or staff press "Placard OK" | This **reverses the self-attested arrival** we had planned: a code the app shows proves nothing, because the judge could read it off the queue without ever reaching the table. The proof has to come off something only the table carries. Bare table numbers also collide across rooms — HackGT had to patch room prefixes into its app on the day of the event | 2026-10-21 |
| 18 | The placard check alphabet is `ACDEFHJKMNPRTUVWXY23479` (23 characters, 529 checks): no 0/O, 1/I/L, 5/S, 6/G, 8/B or Q, and a typed "Z" reads as "2" | Look-alike characters in a loud, dim room. Z is folded rather than added, so the canonical `A14 · W2` stays inside the alphabet and nothing collides. A check holding a character no check has gets a hint and costs no try | 2026-10-13 |
| 19 | The placard QR payload is `https://judging.hackillinois.org/t/<CODE>?k=<k>`, with `k` the full 43-character HMAC over the event, the code and the check. `GET /t/<CODE>?k=…` changes no judging state: it checks the token and swaps it for a 120-second, single-use, httpOnly scan grant bound to the judge and the table, and the redirect carries no token. A `next=` after sign-in never carries `k` | The token is a bearer value, so it must not sit in a URL, in the history or in a Referer. The grant is claimed before the arrive call and given back when the call never reached the server | 2026-10-13 |
| 20 | Wrong typed checks are counted per (judge, table) **across visits** and lock at 5 (`429 CheckLocked`); the QR and the name fallback still work. A look-alike character (O, 0, I, 1, L, S, 5, G, 6, B, 8, Q) gets a hint and counts no miss | A judge in a loud room mistypes. The honest mistake should cost nothing; the guess should cost something | 2026-10-13 |
| 21 | "**Team is busy**" is its own skip reason, separate from absent: no penalty, the visit is deferred, and the project comes back to the same judge first after one other table | Sponsor and MLH judges outside Gav-IL occupy tables, and Jury has the same reason. Without it a busy table is reported as absent and the team is wrongly held | 2026-10-12 |
| 22 | An absent report cools the table for 10 minutes, and **two reports from different judges at least 5 minutes apart auto-hold** the project and open a staff task (Restore / Confirm absent). A team that checks in with the attendee app ends the cool-down but does not release the hold by itself | With only about 2.3 views per project, Jury's threshold of 3 costs more coverage than the absence does. The hold is a review, not a verdict | 2026-10-12 |
| 23 | **The capacity finding is recorded**: 2026's 37 judges for 226 projects is 1:6.1, against Jury's documented minimum of 1:2 and HackMIT 2016's 1:1.8 (about 14 comparison-appearances per project against our 4.2) | It is a finding about **how much data we have**, not about pairwise against a rubric. It says room-local rankings will be noisy, so the dry run checks a room's top-3 stability before we freeze, and the options are at least 1:3 or a longer Round 1 | 2026-10-12 |
| 24 | Every duration and curve is a **motion token** in `tokens.json`, and the reduced-motion block reads those tokens instead of a hand-kept list of exceptions | The motion audit found one 150 ms used for both press and release, a toast that moved the page 54 px under the thumb, a chip that went bold and re-wrapped the row, and a compare card that grew 20 px when selected. All of it is a rule, not polish | 2026-10-21 |
| 25 | The **canonical demo dataset** is one dataset, shared by the prototype and the app: rooms A–D (4217, 4218, 4219, 1404), the projects with room-qualified table codes, 8 judges, 11 prizes and 7 flags, plus p28 "Typo" at D56 as the invalid seed row the validator must reject <!-- refresh --> | Demos and tests have to agree, or a test proves nothing. The prototype and `web/` share the names, the codes and the checks | 2026-10-21 |
| 26 | **External review is part of the definition of done**: every change is checked by second agents (Codex, Cursor, OpenCode, Muse, Agy) and iterated until clean, delegating to cheaper models and free tools; the main session only orchestrates | AGENTS.md rule 10 asks for a second agent before merging. Several agents catch what one misses, and the cheap and free models keep it affordable | 2026-10-21 |
| 27 | Mock mode is **fail-closed**: `GAVIL_MOCK=1` only runs under `next dev` or vitest, the demo shortcuts need `GAVIL_MOCK_DEMO=1`, and a boot assertion refuses either flag anywhere else | A deployed build must never serve fixtures, and a hand-made cookie must never open a shell | 2026-10-13 |
| 28 | Round 2 opens at Round 1's end plus the 15-minute grace, and the **finalist set is frozen from that moment** | Nominees come from nominations, so the set has to stop moving before anybody ranks it. A late evaluation, a late placard proof, a nomination released afterwards or a void vote adds nobody | 2026-10-21 |
| 29 | Deliberation closes 60 minutes after Round 1's end by default | The close is judged on the ranking's own time, so one made before the close still counts when it arrives after it. The 60 minutes is a setting, not a constant | 2026-10-21 |
| 30 | A deployed build serves nothing without a usable `GAVIL_ORIGIN`, and the check runs **per request**, not at boot | A Workers runtime fills the environment only when a request arrives, so a boot check would pass on a broken deploy. The allow-list is the only source; `Host` and `X-Forwarded-Host` are never trusted | 2026-10-21 |
| 31 | The phone **never reads or keeps** the placard `k`, and the arrival's `clientId` is derived from the scan grant's nonce | A token on the phone is a token in a backup and in the URL bar. An id taken from the grant makes a replay the same arrival instead of a second one | 2026-10-21 |
| 32 | The check alphabet is `ACDEFHJKMNPRTUVWXY23479` (23 characters, 529 checks) **in one place**: the app, the mock server, the placard seed and the attendee app's scanner, and a typed `Z` reads as `2` | One alphabet everywhere, so a check typed on the phone, on the sign-in sheet or by the attendee app means the same thing, and the fold cannot collide (see #18) | 2026-10-21 |
| 33 | The **memo window is 15 minutes** after the judge leaves the table | It matches the window a queued upload gets, and it is short enough that a memo never turns into a table recording | 2026-10-21 |
| 34 | The event-level Table talk switch **removes memos as well** as table recordings | One switch, one meaning: while recording is off for the event the phone offers neither, and a memo is a recording like any other | 2026-10-21 |
| 35 | The recorder has a **"Waiting for the microphone…"** state, inside the consent tap | The microphone request has to run inside the gesture (iOS opens the mic only from a tap), so the card waits for the engine and nothing says Recording before it is listening | 2026-10-21 |
| 36 | The mic engine is **`MediaRecorder` plus server transcription only**: no browser speech recognition, no live captions | A browser's own recognizer sends the audio to Google or Apple, which the consent script does not name, and nothing on the screen should repeat what a team said | 2026-10-21 |
| 37 | **"Stop and delete"** throws the recording away, and the try it used stays used | A judge who hears something wrong can drop it, and the table does not lose a try to a mis-tap | 2026-10-21 |
| 38 | The OpenPencil spec sheet lives in **`design-system/design/`** and is generated by `scripts/make_spec_sheet.mjs` | The sheet follows the tokens and the components instead of drifting from them, and `--check` audits it in one command | 2026-10-21 |
| 39 | The real 2027 brand art is **exported from the 2027 Figma files into `design-system/assets/brand/`** and is never redrawn | Rule 2 is "never redraw". The export was made by hand through the Figma web UI, and `MANIFEST.md` records every file, the Figma file and node it came from, and its intended use | 2026-10-21 |
| 40 | External review **falls back to the free OpenCode models** when Codex, Cursor, Agy or Muse has no quota left | The second opinion is a rule, not a preference (see #26): a quota wall must not stop the check, and the cheap models keep it affordable | 2026-10-21 |

## Open

| Question | Options | Owner |
|---|---|---|
| **Legal sign-off on Table talk** | The Illinois Eavesdropping Act (all-party consent for a private conversation) and BIPA (voiceprints) both apply. Counsel has to approve the consent script, the participant notice and the retention schedule before the event switch goes on; until then the feature is off | HackIllinois leads + UIUC counsel |
| **Who prints the placards** | The codes and the checks are drawn at seed time, so the run must be printed before the doors open. A reprint after a room change means new checks, and rotating the checks per round would be stronger against a copied placard | Floor staff |
| **Workers AI or another transcription vendor** | Whisper turbo on Workers AI is about $1.30 for a whole event, but at 0 dB SNR Whisper Large goes from 2.1% to 21.3% word error rate. Deepgram Nova-3 (about $11, with keyterm prompting of the Devpost terms) and AssemblyAI (about $9) are the upgrade path; decide with a sound-level meter in the real rooms | Aritro + Jacob |
| **Figma MCP access** | The Figma MCP server refuses every read of the 2027 Design System, Registration and Gav-IL files with "you don't have edit access to this file" for the account we have, and the draft copies of the three files sit in an education team's Drafts space that is still view-only. The art is out of the way now (it was exported by hand on 2026-10-21), so what is open is read access to the files themselves | Jacob + the design team |
| **Who owns brand re-exports** | The 2027 files have no dark H mark (Figma only has the white one) and no standalone sheriff star or rosette, so those cannot be produced at all yet. Anything wrong in `design-system/assets/brand/` is re-exported from Figma, never redrawn: who asks for that, who runs the export and who signs the file off is not decided | Jacob + the design team |
| Where admin lives | Judging admin as routes inside the existing `admin-site`, **or** an `/admin` area inside GavIL. `admin-site` already has MUI + DataGrid; GavIL's console uses this design system | Jacob + Aritro |
| Design system in code | Port `design-system/` tokens + components into the Next.js app (CSS variables + React components), or as MUI theme overrides if admin goes into `admin-site` | Jacob + Aritro |
| `Room-Setup` repo | It is empty ("setup rooms for judging"); fold room seating data into adonix or keep separate | Jacob + Aritro |
| Pairwise algorithm | Gavel's CrowdBT per path and room, with a coverage floor (no project below 2 views) and room-local queues so judges don't change floors | Jacob + Aritro |

Still missing: a dark H mark, a standalone sheriff star or rosette, the other painted background variants, and the QR, which is still a placeholder | Design team |
