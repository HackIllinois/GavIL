Gav-IL mobile test suite

Runs every judge and admin scenario in a 390 × 844 frame (iPhone 14). Build first: python3 scripts/build_previews.py. Add ?theme=night to run on the Night theme, ?only=Round 2 to report just the suites whose name contains that text (the tests before the last of them still run, silently, because the suites are one flow; add &fresh=1 to skip them for a suite that loads its own page). node scripts/run_tests.mjs runs both themes headless. It is built to pass in a hidden or throttled tab: it waits for animations (and finishes them) instead of sleeping, seeks animations to check motion, and times double taps with a yield that timers can't throttle. On a machine that asks for reduced motion it pins full motion for the motion checks (the reduced-motion suite still runs reduced).
