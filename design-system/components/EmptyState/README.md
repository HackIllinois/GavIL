# EmptyState

What a list shows when there's nothing in it, with the next useful action. It carries its own paper, so it reads on ground.

- **Provide:** `title`, optional `prop`, `icon`, `body`, `action`, `as` (heading level: `h1` when the card is the page's only heading, as on Round 2 before it opens).
- `prop` draws a brand prop above the title (`wagon`, `cactus-tall`, `cactus-round`, `horseshoe`; see `Prop`) in place of the icon medallion: use it for a judge's own empty states (My notes, a finished queue); the console keeps the icon where space is tight. The prop is decorative (`alt=""`).
- On ground it is a paper card; inside a Card or table it drops its own paper.
- Say what is true and what happens next; never "Nothing here!".
- A `prop` that does not arrive gives way to the icon medallion (`icon`, default `inbox`), so the card never shows a broken-image box.
