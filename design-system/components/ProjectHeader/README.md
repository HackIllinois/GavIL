# ProjectHeader

Top card of the evaluate screen, a wanted poster: path, tracks, a ruled eyebrow, the project name and tagline.

- **Provide:** `name`, `path` (`pro`|`general`), `table`, `room`, optional `tracks` (company tracks, e.g. `['Modal']`), `tagline`, `eyebrow` (string, or false; default "Table A12"), `seen` (admins only), `showLocation` (false when an inline Wayfinding already shows room and table), `as` (heading level; `h1` on the evaluate screen, where the project name is the screen's title).
- The eyebrow is `ink-soft`, never path-colored. Taglines are upright (Manrope has no italic).
