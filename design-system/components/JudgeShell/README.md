# JudgeShell

Phone frame for every judge screen: wood app bar (plus TimerBar during judging), scrolling body, optional sticky footer and a toast dock, capped at `phone-max`.

- **Provide:** `children`, optional `timer` (a TimerBar under the app bar; it replaces the sky strip), `right` (app-bar actions; always rendered, so My notes never disappears), `footer` (an ActionBar), `toast` (+ `toastId`, `toastTone`), `offline` + `queued` (the compact OfflineBanner takes the wordmark's place in the app bar, so going offline moves nothing on the screen), `unsent` (`{n, onRetry}`: back online with work the server didn't take, a paper tag "2 not sent · Tap to retry" takes the wordmark's place until everything is sent; a failed item is never dropped; its name is those words, then "Saved on this phone" for a screen reader, with no aria-label), `recording` (`{elapsed, paused, memo, onShow}` while Table talk records: see below), `screenKey`, `announce` (a sentence for the one polite live region, e.g. "Now judging NeuralMesh, table A12." when a loading project arrives; if focus is still parked on the body, it moves to the new heading).
- On a screen change focus moves to the new screen's first heading (`h1`/`h2`; give every screen one), or to the body while it is still loading, so keyboard and screen-reader judges are never dropped on the page. If focus is in a dialog or outside the shell, the live region says the new title instead.
- Change `screenKey` per screen (and per project): the body re-mounts at the top and rises in. Prefer `GavIL.swap(update)` for screen changes: a View Transition when available, else this CSS fallback.
- Handles the notch (`safe-area-inset-top`), landscape insets and stops pull-to-refresh on judge pages.
- **Landmarks:** the app bar and the timer under it are one `header` (the banner: a timer outside any landmark is skipped by landmark navigation); the screen is the `main`; the dock is a `region` named "Actions" whenever it holds a footer (Submit and Skip are not outside the page).
- **Sticky bands:** the shell measures the two bands that stay on screen (the app bar with its timer, the dock) and writes their heights to `--gv-top-h` and `--gv-dock-h` on the root; the stylesheet turns them into `scroll-padding`, so a control reached with Tab or Shift+Tab scrolls out from under them (WCAG 2.2, 2.4.11). A screen that sizes its first view reads `--gv-top-h` (the walk: see EnRoute). Without a shell both are 0.
- **Recording, pinned:** while Table talk records, pass `recording`. A paper tag in the record red (`rec`) with a dot and the elapsed time takes the wordmark's place on every screen (beside the offline tag when offline, which then shortens to "Offline."), so the word **Recording** never scrolls out of the team's sight. It says **Recording paused** (grey dot) while paused; its dot breathes on `dur-rec-pulse` and holds still under reduced motion. With `onShow` it is a 48px button that brings the recorder back. It is named by its visible words, "Recording", then "Show the recorder" (and "your memo") for a screen reader, with no aria-label, so the visible text is part of the name (WCAG 2.5.3); the ticking time is hidden from screen readers.
- **Brand:** the app bar carries the HackIllinois lockup (`Brand name="lockup"`, white on wood, 40px tall). Behind the content is the painted ground (`gv-ground`, art-ground: the sunset or the night canyon, cover-fit, fixed, under the `scrim` token): only titles, eyebrows and ledes sit on it, every piece of content sits on paper, and an eyebrow on it is a plum plaque (`gv-step`). Pass `ground={false}` to leave it out (a print sheet). A preview that stacks more than one shell wraps each in a `transform` frame, because the painting is fixed to the viewport, or to the nearest transformed ancestor.
