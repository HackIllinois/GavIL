# TableCheck

The right-table check at the table: ask the team, then scan the placard QR or type its code with the 2-character check. Notes, nominations, Table talk and Submit stay locked until it matches.

- **Provide:** `project` `{name, table, team}`, `room`, and either `state` + `result` (controlled: you check the code) or `verify(input)` (returns, or resolves to, a result). `input` is `{method: 'code'|'qr', code, check, k?, raw}`. Also `value`/`onChange` (the typed text) or `defaultValue`, `via` (`'qr'`|`'scan'`|`'code'`, for the matched line), `triesLeft`, `onScan` (**Scan table QR** shows only when it is given: a parent that can’t open a camera offers none), `onCancelScan`, `scanPreview` (what the viewfinder shows), `onCheck`, `onRetry`, `onName` (shows the placard fallback), `onMap`.
- **States:** `idle`, `scanning` (a camera viewfinder in a `role=dialog` named "Scan the table QR"; focus starts on **Cancel scan**, Escape cancels, focus goes back to **Scan table QR**), `checking`, `matched`, `mismatch` (`result: {code, name, direction}` → "A14 is LedgerLite. NeuralMesh is at A12, two tables to your right."; with no `name` and `offline: true` it reads "A14 isn’t NeuralMesh’s table" and says the app can’t name the team while offline), `needs-check` (the code matched but the check is missing or wrong: "Type the 2 characters after the dot on the placard."; a missing check costs no try; `result.message` replaces the line, e.g. a look-alike hint or why a check typed offline didn't match on reconnect), `not-found`, `offline` (the check, or the scan's token, is kept and sent on reconnect; **it is never “matched” until the server says so**, and offline still asks for the 2 characters), `name`, `locked` (5 wrong checks: typing stops; scan and the team’s name still work), `no-camera` (the camera is blocked: type the code), `failed`.
- **Placard codes:** the table code plus a 2-character check that only the placard prints ("A12 · K7"; the app never shows the check before arrival, and the phone never holds one: the server compares). One field takes "A12K7", "a12 k7" or "A12 · K7", upper-cases it and draws the dot itself. A pasted placard URL checks as a scan only when it carries the QR's signed token (`?k=`); a bare `/t/A12` just fills in the code and still asks for the check. The check alphabet is `ACDEFHJKMNPRTUVWXY23479` (no look-alikes); a typed Z reads as 2, and `GavIL.checkHint(check)` names a misreading (the look-alikes O, 0, I, 1, L and S, 5, G, 6, B, 8, Q) without costing a try; the preview server counts none of them as a miss either. `GavIL.parseTableCode(text)` gives `{code, check, k}`.
- `GavIL.mockServer` is the previews' stand-in for adonix's judge routes (`arrive`, `sync`, `policy`). It is demo data only: four made-up checks (A12 · K7, A17 · M3, A20 · T9, A22 · R4), a made-up QR token (`demo-<code>`) and no route that lists or issues a placard, so nothing in the judge bundle can reveal a check before arrival. It answers `matched`, `mismatch` (WrongTable, naming the project there), `needs-check` (CheckRequired / BadCheck), `locked` or `not-found`. A real app calls its server the same way.
- The field is Oswald at 24px (never under 16px, so iOS never zooms), `inputMode=text`, `autoCapitalize=characters`, no autocorrect, Enter checks.
- A mismatch names the project at that code and says where the right table is; it never asks for the check of the wrong table. A missing or wrong check never counts against the team.
- **Name fallback** (damaged or missing placard): "They told me they’re NeuralMesh" asks a second question (**Did the team say “NeuralMesh” themselves?** Yes, they said it / Back), then unlocks notes, nominations and Submit as **Confirmed by name · staff may check**. It can’t report the team absent, can’t start Table talk, and its nominations are held until staff check the table.
- Matched folds the card into one strip with a check that stamps in (`ease-stamp`; it just appears under reduced motion), buzzes `success`, says "Right table" once to screen readers and keeps focus on the strip. Errors buzz `error`.
- The QR on the placard encodes the TABLE (`https://judging.hackillinois.org/t/A12?k=<signed token>`), never the project, so moving a team needs no reprint.
