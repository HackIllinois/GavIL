# TablePlacard

A printed table placard (US Letter, one per page): the room's colour band, the huge table code, its 2-character check, the QR of the table and "Judges scan here". The project slot is blank unless a name is asked for.

- **Provide:** `code` (`A12`), `check` (`K7`), `label` (the code and its check exactly as printed, `A12 · K7`, which is what adonix's placards route returns; without it `code` and `check` make it), `room` (`4217`) or `roomName`, optional `letter` and `color` (default from the code: A Gold, B Teal, C Rose, D Sage), `k` (the QR's signed token, 43 characters in production: the full token goes in the QR, never a prefix) or a full `url`, `project` (printed in the name slot; **leave it out and the slot stays blank, to write by hand: a team that moves then needs no reprint**), `notice` (the paragraph teams read when Table talk is on, `GavIL.talk.copy({ai}).notice`; the first placard above shows it), `where`, `scale` (on-screen thumbnail; print is always full size).
- The QR encodes the TABLE: `https://judging.hackillinois.org/t/A12?k=<signed token>` (`GavIL.placardUrl(code, k)`), never the project, so moving a team needs no reprint. It is drawn by qrcode-generator 1.4.4 (pinned); if that fails to load, the scan block becomes one centred line, **Judges type this code** ("Open the judging app and type A12 · K7."), never an empty box beside "scan here".
- The room band uses `room-a` … `room-d` with their `on-room-*` text; the code uses `--type-placard-code` (Oswald, readable across the aisle) and the check `--type-placard-check`.
- The check ("· K7") appears only on the placard: the judge app never shows it before arrival. In previews the console carries a mock list with made-up checks; a real console reads them from adonix (STAFF and ADMIN only), and the judge bundle has no route that lists or issues one.
- Print colours exactly (`print-color-adjust: exact`); size from `placard-w` × `placard-h` (7.5 × 9.9 in inside 0.5 in margins, 0.1 in short of the printable height so a page never spills a blank sheet).
