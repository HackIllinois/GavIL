# TableTalk

Judge-private recall notes from the table conversation, only after the team agrees: a premium recorder (72px control, calm red pulse, live level, Oswald timer, Mark this moment) and every failure state designed.

- **Provide:** `state`, `mode` (`'table'` | `'memo'`), `project` (name, for copy), `elapsed` (s), `level` (0–1), `marks` (s), `warn` (one minute left), `pausedReason` (`'screen'` | `'interrupted'`: the microphone track was muted, e.g. a call; the card says so and needs a tap to resume), `eligibility` (`GavIL.talk.eligibility({eventEnabled, projectOptedOut, judgeSupported, mode})`: when it is not allowed the card shows its reason and next step and no **Ask and record**, and the parent asks it again in the consent tap, before the engine starts and before Resume), `supported` (`false` shows "This browser can’t take voice notes" before the judge can ask the team), `attemptsUsed` / `maxAttempts` (one recording + one retry: 2), `meta` ("1:52 · 241 words"), `demo` (labels the transcript "Demo transcript. Your audio wasn’t sent anywhere."), `highlights` (`HighlightList` props), `disabled` + `lockedReason` (before the table check matches), `lockedReason`/`lockedSub` (for `locked-by-admin`), `failedAt` (`'start'`: the microphone never opened), `ai` (`false` drops Anthropic from the consent script when AI summaries are off), and callbacks `onAsk`, `onConsent`, `onDecline`, `onCancelConsent` (optional: whatever way the consent sheet ends, the card hushes it itself and shows **Ask and record** again, so a parent that leaves `state` on `consent` never strands an invisible sheet over an inert page. A lock that arrives while the sheet is open (the event switch, an opt-out, the table check) closes it too, says so once in the live region and calls `onCancelConsent`, so the parent leaves `consent` and the sheet never opens again by itself when the lock lifts), `as` (the title's heading level, `'h2'` by default: the card sits under the screen's h1), `onCancelStart`, `onMark`, `onPause`, `onResume`, `onStop`, `onStopDelete`, `onRetry`, `onStart` (memo), `onDiscard`.
- **States:** `idle` → `consent` (renders `ConsentSheet`) → `starting` ("Waiting for the microphone…": nothing records yet; **Cancel** lets go) → `recording` ⇄ `paused` → `processing` → `ready`; `declined` ("Dictate a memo after you leave"), `retry` (one more try), `used-up`, `memo`, `unsupported`, `denied` (with how to allow the mic), `mic-busy`, `offline-queued` ("Your notes from this table wait on this phone": pulled out when the judge reconnects; discarded unheard if they’re not back within 15 minutes of leaving the table, which the parent enforces with `talk-window`; a reload discards them too), `too-noisy` (a memo says "Couldn’t make out the memo"), `failed` ("Couldn’t transcribe this one"; with `failedAt: 'start'`, "The microphone didn’t start": nothing heard, no try used), `locked-by-admin` (event switch off, or the team opted out). A lock that arrives mid-recording is the parent's to act on (stop the engine, let go of the microphone, return `state` to `idle`/`retry`/`used-up`) and to say: a toast or live message "Recording stopped. … Nothing was kept." and a warn buzz, because the judge may be looking at the team, not the phone. A `processing` card that has waited `talk-processing-timeout` (30 s) turns into "Highlights are taking longer than expected" with **Record again** (`onRetry`, while a try is left) and **Continue without highlights** (`onDiscard`), so a request that never returns is never a dead end. When the deadline passes the live region says so once and focus moves to the message (it stays put if the judge is typing elsewhere).
- The parent owns the engine (`GavIL.talk.FixtureEngine` / `MicEngine`, one interface: `supported start pause resume stop discard elapsed onSegment onState onLevel`) and starts it only from `onConsent`, which runs inside the consent tap. **Recording shows only when the engine says it is listening** (`starting` until then). **Every pause, hidden page, screen change or lock releases the microphone** (every track is stopped); **Resume** needs a new tap and a fresh stream. There are no live captions and no browser speech recognition: nothing on screen repeats what is said, and no audio goes to a recognizer the consent script doesn’t name. Decline stores nothing; Escape on the consent sheet only closes it. Memo mode skips the consent sheet but is only offered after the judge has left the table (never at a table that declined or opted out), never when Table talk is off for the event, and never when the microphone is blocked or unsupported. A memo gets one retry too (**Record the memo again**).
- **Recorder:** the word **Recording** and a red dot are always on screen while it records; elapsed time in tabular Oswald (`--type-stat`); `LevelMeter`; **Pause/Resume**, a 72px **Stop** disc (`rec-size`) with a calm breathing halo (`dur-rec-pulse`, static under reduced motion) and **Mark this** (a `tap` buzz; badge "Marked 01:04"); **Stop and delete** (confirms inline; stops the microphone and keeps nothing, and the try it used stays used). The privacy line is always there and says what the consent script says: "The audio isn’t kept: it’s deleted once it’s transcribed." While it records, `JudgeShell` also pins a **Recording** tag in the app bar on every screen. Side controls are 72px tall; nothing is under 48px.
- The polite live region says only state changes (waiting, recording, paused, marked, highlights ready): never the timer, never transcript words. Focus never drops to the page: after Stop it lands on the processing status, then on the first **Keep**; after a start it lands on Stop.
- It never blocks Submit or Skip. The one hold is the parent's, not the card's: the tap that says "Everyone agreed" sits over Submit, so while the microphone is starting ("Waiting for the microphone…") the prototype's Submit ignores finger taps for at most `talk-start-hold` (8 s; a key or assistive-tech press always acts), and the sheet's button footprint is shielded for `dur-retap` after the sheet closes. Ready shows `HighlightList`; **Delete what was heard** confirms inline, naming the project.
- Placement: between the project disclosures and Private notes. `DemoStatus` follows it.
