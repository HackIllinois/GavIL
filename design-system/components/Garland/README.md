# Garland

A row of horses on a line between two sections: cream on the painted ground, brown on paper. Decorative.

- **Provide:** `tone` (`ground` default, `paper`), `className`.
- Use it where a screen changes subject: between the project and your own notes on the evaluate screen, under the My notes heading, between Round 1 complete's lede and its sign. One garland per break; never two in a row, never as a bullet.
- It is an `<img>` with `alt=""` and `aria-hidden`: it carries no meaning, so no one hears it. Cream on the scrimmed ground is at least 3:1 in both themes (measured); brown on paper is the same art in the Figma sheet's brown.
- If the file does not arrive it leaves the layout (`data-art="failed"`): no broken-image box, and the sections it divided still read.
